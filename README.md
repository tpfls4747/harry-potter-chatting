# Magic Chat — 해리 포터 챗봇 🪄

카카오톡처럼 대화하는 모바일 앱 스타일의 해리 포터 챗봇입니다. [Groq API](https://console.groq.com)로 동작하며,
설치·빌드 없이 `index.html`만 열면 실행됩니다. (일기장 양피지 효과는 magic-ink 프로젝트를 참고했습니다.)

## 빠른 시작
1. `index.html`을 더블클릭해 브라우저(Chrome/Edge 권장)로 엽니다.
2. [console.groq.com/keys](https://console.groq.com/keys)에서 발급받은 API 키(`gsk_...`)를 입력합니다.
3. **친구** 탭에서 대화 상대를 고르면 바로 대화가 시작됩니다.

## 두 가지 모드
| 모드 | 설명 |
|---|---|
| 📖 **질문 답변 모드** | "해리 포터 박사"가 원작 소설 7권과 영화 8편 기준으로 답합니다. 책과 영화가 다른 부분은 📖 책 / 🎬 영화로 구분하고, 큰 반전이 나오면 스포일러 경고를 먼저 붙입니다. |
| 🎭 **캐릭터 역할놀이 모드** | 해리, 헤르미온느, 론, 덤블도어, 스네이프, 해그리드, 말포이, 루나, 시리우스, 맥고나걸, 프레드&조지, 도비, 톰 리들 — 총 13명이 각자의 말투와 성격으로 대화합니다. |

## 화면 구성
- 하단 탭: **친구**(대화 상대 목록) / **채팅**(대화 목록, 안 읽은 알림) / **설정**
- 채팅방: 노란 내 말풍선, 상대 프로필·이름, 날짜 구분선, 시간, 입력 중 표시, 실시간 타자 출력
- 응답 중에는 전송 버튼이 ■ 정지 버튼으로 바뀌고, 실패하면 "다시 시도" 버튼이 나옵니다.
- PC에서는 Enter 전송 / Shift+Enter 줄바꿈, 모바일에서는 Enter가 줄바꿈입니다.

## 대화창 배경
캐릭터마다 어울리는 배경이 자동 적용됩니다.

| 배경 | 캐릭터 |
|---|---|
| 🏰 호그와트 성 | 해리, 루나 |
| 🗺️ 호그와트 지도 | 해리 포터 박사, 헤르미온느 |
| 🏆 트리위저드 대회장 | 론, 프레드 & 조지 |
| 🕯️ 대연회장 | 덤블도어, 맥고나걸, 도비 |
| 🧪 지하 마법약 교실 | 스네이프, 말포이 |
| 🌲 금지된 숲 | 해그리드, 시리우스 |
| 📓 양피지 일기장 (고정) | 톰 리들 |

채팅방 오른쪽 위 **⋮ 메뉴**에서 방마다 다른 배경으로 바꿀 수 있고, "✨ 캐릭터 기본 배경으로"로 되돌릴 수 있습니다.
배경은 이미지 파일 없이 SVG/그라디언트 코드로 그려집니다.

## API 키 보안
- 키는 **내 브라우저 → Groq 서버**로만 전송됩니다. 코드·주소창·대화 저장 데이터에는 포함되지 않습니다.
- 입력칸은 가려져 있으며(👁로 확인), 자동완성이 되지 않도록 설정했습니다.
- 기본은 **임시 저장**(sessionStorage)이라 탭을 닫으면 삭제됩니다. "이 기기에 키 기억하기"를 켜야만 계속 저장됩니다.
- 설정 탭에서 **키 변경 / 키 삭제**가 가능하며, Groq가 키를 거부(401)하면 자동으로 삭제합니다.
- 공용 PC에서는 "기억하기"를 끄고, 사용 후 키를 삭제하세요. 키가 담긴 화면 캡처·공유 링크를 올리지 마세요.

## 설정
- **닉네임**: 캐릭터가 나를 부르는 이름
- **AI 모델**: 기본은 `llama-3.3-70b-versatile`(한국어 품질이 좋은 모델)을 자동 선택합니다. 직접 고르면 그 선택을 유지하며, "모델 목록 새로고침"으로 최신 목록을 가져옵니다.
- **연결 테스트**: 키·모델·네트워크가 정상인지 한 번에 확인하고 실패 원인을 보여줍니다.
- **모든 대화 삭제**: 저장된 대화 전체 삭제

## 문제 해결
| 증상 | 확인할 것 |
|---|---|
| 키 오류 메시지 | `gsk_`로 시작하는 키를 다시 입력 |
| 요청이 너무 많다는 메시지 | Groq 무료 한도 초과 — 잠시 후 재시도 |
| 모델 오류 | 설정에서 다른 모델 선택 |
| 연결 오류 | 인터넷, 회사/학교 네트워크·방화벽·백신이 `api.groq.com`을 막는지 확인 |
| 답이 이상하거나 한국어가 깨짐 | 설정에서 모델이 `llama-3.3-70b-versatile`인지 확인, 채팅방 ⋮ → "대화 내용 지우기" |

## 파일 구성
```
index.html     화면 구조 (설정 / 메인 탭 / 채팅방)
style.css      카카오톡 스타일 디자인, 배경 테마 색상
characters.js  챗봇·캐릭터 정의와 시스템 프롬프트
app.js         앱 로직 (Groq 스트리밍, 대화 저장, 설정, 배경 테마)
```

## 데이터 저장
대화 내용·닉네임·모델·배경 선택은 이 기기 브라우저(localStorage)에만 저장되며 서버로 보내지 않습니다
(대화할 때 모델이 답하기 위해 Groq로 메시지가 전송되는 것은 제외).

## 참고
- 캐릭터는 해리 포터 원작 설정을 바탕으로 한 팬 롤플레이이며, 실제 인물·기관과 무관합니다.
- 모델의 답변은 틀릴 수 있습니다. 중요한 내용은 원작으로 확인하세요.
